# Bundled third-party notices

The maker copies these texts and the actual wheel license files into
`Contents/Resources/third-party-notices`. `python-packages.md` lists the shipped
distribution versions. CPython retains its own license in the bundled Python
tree; Electron and Chromium notices are copied from the selected Electron
distribution. Production npm package licenses remain beside their packages in
`app.asar/node_modules`.

PortAudio's original license is retained for the library vendored into audio
wheels. uv is distributed under MIT or Apache-2.0; both original license texts
are included here.

The AOQ frameworks must be supplied from the official SDK under its applicable
distribution terms. No MiraJelly implementation, personal credentials or
official Codex/Computer Use binaries are included in this source change.
