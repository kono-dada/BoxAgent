# 伙伴与聊天显示屏

在聊天框右上角的显示器菜单，或伙伴控制台「设置 → 语音与桌面」分别选择**展示形态**和**伙伴与聊天显示屏**。菜单栏的「伙伴与聊天显示屏」也提供这两个设置。

- **桌宠**是新配置的默认形态。主屏、普通副屏和随拖动跨屏都能用透明桌宠。角色原地做动作，小窗通常宽 414 点，高度随内容变化，上限 345 点。标题贴近肩部并随人物一起拖动。边缘空间有限时可停靠到另一侧或上下方。小窗保留文字输入和标题栏任务灵动岛。
- **无触屏硬件**在指定的副屏上启用全屏舞台，默认雾紫。横屏让聊天靠一侧，宽度通常为 360–480 点、高度约不超过八成。窄屏按可用空间调整。小窗或展开的任务面板占用时为它们留出位置，收起后角色恢复整屏活动空间。
- 在伙伴控制台「设置 → 语音与桌面 → 副屏背景」可切换雾紫和经典粉红。选择立即应用到硬件舞台，断开副屏或改用桌宠时继续保留。
- 主屏或副屏断开时，以透明桌宠展示，硬件偏好和屏幕选择继续保存。原副屏重新接入后自动恢复。日常与陪玩由陪玩开关控制，沿用当前展示形态。
- 指定屏幕后，伙伴、聊天和任务展示都在该屏。选择「随拖动切换屏幕」回到主屏，之后可拖动整组跨屏。
- 展示形态与屏幕独立保存在本机数据目录 `display.json`。旧配置曾指定副屏时，升级为硬件偏好并保留屏幕。旧配置选择主屏或随拖动时，升级为桌宠。
- 同时保存显示器编号和名称。重启或重连导致编号变化时，按唯一匹配的名称找回所选屏幕；若同名设备有多台且原编号不再匹配，则回到主屏，需重新选择，不猜测目标。旧配置的编号仍有效时会自动补记名称。
- 屏幕必须使用扩展模式。镜像模式不能将不同内容分别放在两块屏幕上。
- 在 macOS 的全屏应用内可以点桌宠展开聊天，语音与文字输入都留在当前空间。伙伴控制台仍以普通窗口打开。
- 独立显示模式按人物实际可见区域适配大小。硬件形态在 100% 时以约八成可用屏高作为含动作留白的目标，最终尺寸取决于模型与布局。在「设置 → 3D 形象」的大小滑杆可继续调整，桌宠与硬件共用滑杆保存的百分比，各自计算实际尺寸。

## 聊天与陪玩

- 收起聊天时，短回复和微信来信以角色旁的气泡呈现，任务执行进度显示在角色脚下。展开后，任务进度显示在标题栏的任务灵动岛。
- 桌宠小窗等待 20 秒自动收起，硬件副屏等待 12 秒，长回复多留阅读时间。讲话、输入、未发送草稿、翻看历史和等待确认时暂停。可以说「展开聊天」「收起聊天」或「先留着」。
- 游戏处于前台时，右侧半头像可以展开麦克风、游戏短评和结束陪玩控件。关麦或静音后控件仍展开。关麦会停止输入，静音会打断当下的游戏短评，微信与普通对话可以继续播报。
- [交互设计稿](design/companion/index.html)可在浏览器中试用，包含两种显示形态和模拟消息。页面保留原型尺寸，实际运行尺寸以上文为准。

## 实现与验证

原生窗口由 Electron DesktopHost 布局，使用系统逻辑坐标和工作区。Python 桌面服务提供前台游戏窗口位置，游戏控制按钮通过 Engine 切换语音和陪玩状态。
`desktop_set_pet_display` 接收显示器字符串 ID 或 `null`，`desktop_set_display_profile` 接收 `desktop` 或 `hardware`。
热插拔和工作区变更同时处理当前及正在预加载的形象，并在退出时注销监听。
渲染器首次上报可见边界后校准缩放；拖动约束使用裁剪后的窗口。窗口保留首帧边界，独立显示时额外预留固定动作边距（左右各 12%、上下各 6%，不超出原画布）。后续动作或诊断截图不再触发窗口缩放；手动缩放、切换屏幕与热插拔均从首帧边界计算，避免反复取整积累误差。虚拟渲染画布可以超出屏幕，实际人物窗口保持在屏内。大幅动作仍可能超出裁剪范围，这是固定边界策略的限制。

角色的渲染窗口始终鼠标穿透且不接收焦点。硬件模式在指定副屏铺满场景背景，桌宠模式的渲染层保持透明。桌宠的鼠标命中范围按首帧人物轮廓计算，透明空白和投影透传点击。macOS 上控制台聚焦时覆盖桌宠的显示和鼠标窗口，失焦时回到普通窗口层级。

验证：`pnpm --dir web/panel test`、`pnpm --dir web/panel build`。
`desktop-displays.test.cjs` 覆盖分屏、独立拖动、通知、热插拔、旋转、缩放、换装、配置恢复及默认行为回归。

连接扩展副屏后，在 `web/panel` 运行 `pnpm exec electron tests/desktop-smoke.cjs --displays` 可进行真实双屏测试；它使用隔离的数据目录、模拟 Engine 和真实 VRM，不调用云端模型或打开麦克风/摄像头。
测试校验角色画布随跨屏切换使用相应的像素密度，上限 2×。设置 `BOXAGENT_DISPLAY_SCREENSHOTS`（输出目录）即可保存副屏舞台和聊天截图。额外的 Playwright 截图需要同时设置 `BOXAGENT_PLAYWRIGHT_MODULE`（Playwright 模块路径），并添加 `--remote-debugging-port=9224`。

2026-11-17 本机修复验收：98 项桌面测试通过；真实双屏覆盖副屏背景、主屏透明、最大缩放与聊天/任务避让。渲染失败和退出后的晚到回调不会再对已销毁窗口调用 `setBounds`；当前人物渲染失败会清理失效命中层并保留可操作的错误反馈。已安装包重开后严格签名校验通过；Jev-Mem 子进程继承缓存目录并禁写字节码，避免在 App 内新增 `__pycache__` 破坏签名。凭据读取按文件内容缓存，配置变化后失效，不关闭系统钥匙串或 Cookie 加密。
