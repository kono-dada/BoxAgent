# 桌宠分屏显示

在聊天框右上角点击显示器图标，选择 `副屏 · 显示器名称`。
也可以从菜单栏图标的「小人显示屏」，或伙伴控制台「设置 → 语音与桌面 → 小人显示屏」选择。

- 选择一块屏幕后，小人独立放置在该屏，聊天和任务面板留在系统主屏。
- 拖动、缩放、换装以及新消息展开聊天不会将另一块屏上的窗口一起带走。
- 选择「小人与聊天同屏」恢复原来的联动布局，并回到主屏。
- 选择保存在本机数据目录 `display.json`，重启保留；副屏断开时临时回到主屏，同一显示器重新接入后自动恢复。
- 同时保存显示器编号和名称。重启或重连导致编号变化时，按唯一匹配的名称找回所选屏幕；若同名设备有多台且原编号不再匹配，则回到主屏，需重新选择，不猜测目标。旧配置的编号仍有效时会自动补记名称。
- 屏幕必须使用扩展模式。镜像模式不能将不同内容分别放在两块屏幕上。
- 独立显示模式按人物实际可见区域适配大小，不再用含透明留白的横向画布限制竖屏放大。大小仍在「设置 → 3D 形象 → 桌宠大小」调整，最大 600%；最终以全身能够放进屏幕为限。

实现只在 Electron DesktopHost 的窗口布局层，使用系统逻辑坐标和工作区，不修改 AOQ、摄像头、模型或 Python 服务。
`desktop_set_pet_display` 接收系统枚举出的字符串显示器 ID；`null` 恢复联动布局。
热插拔和工作区变更同时处理当前及正在预加载的形象，并在退出时注销监听。
渲染器首次上报可见边界后校准缩放；拖动约束使用裁剪后的窗口。动作变宽超出屏幕时自动缩小，普通待机动画不反复放大，避免画面不断变焦。虚拟渲染画布可以超出屏幕，实际人物窗口保持在屏内。

验证：`pnpm --dir web/panel test`、`pnpm --dir web/panel build`。
`desktop-displays.test.cjs` 覆盖分屏、独立拖动、通知、热插拔、旋转、缩放、换装、配置恢复及默认行为回归。

连接扩展副屏后，在 `web/panel` 运行 `pnpm exec electron tests/desktop-smoke.cjs --displays` 可进行真实双屏测试；它使用隔离的数据目录、模拟 Engine 和真实 VRM，不调用云端模型或打开麦克风/摄像头。
如需 Playwright 截图，同时设置 `BOXAGENT_PLAYWRIGHT_MODULE`（Playwright 模块路径）、`BOXAGENT_DISPLAY_SCREENSHOTS`（输出目录），并添加 `--remote-debugging-port=9224`。
