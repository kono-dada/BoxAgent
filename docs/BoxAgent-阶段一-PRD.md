# BoxAgent 阶段一 PRD

## 第一次真实使用

本阶段的目标是让用户在一分钟内感受到：BoxAgent 不是一个等待被打开的聊天窗口，而是一个常驻、能注意环境变化、随时回应并完成受控动作的电脑伙伴。

1. 用户回到 Mac 前，系统根据键鼠从空闲恢复判断用户已回来；屏幕里的 BoxAgent 从休息切换到关注状态，但保持安静。
2. 用户通过点击、快捷键或当前语音入口召唤 BoxAgent；它立即切换到倾听状态，先用动作和短提示确认已听见，不让模型延迟表现为无响应。
3. 用户说：“我要看会儿视频，声音小一点。”BoxAgent 结合前台应用和媒体状态理解意图，在不需要额外确认时调低系统音量，不改变视频的其他状态。
4. 执行后，系统读取真实音量状态；BoxAgent 用一句话和完成动作反馈结果，失败时则明确说没有完成，不用话术代替真实成功。
5. 交互结束后，BoxAgent 回到安静常驻状态；只有之后出现用户明确关心的变化，它才通过动作或一句话介入。

这一分钟的闭环同时建立了常驻存在、低摩擦召唤、环境理解、角色反馈、受控行动和真实结果验证六个阶段一概念。
