# 形象商店

## 使用

右键桌宠或菜单栏 ◉，打开「形象商店…」。输入名称搜索、使用上一页／下一页浏览，点击「下载并使用」即可切换桌面形象。切换时暂停搜索、筛选和分页操作，窗口保留进度提示；成功后保存选择，失败继续显示原形象。

「已下载」完全离线读取本机资源；「换回小鸭」恢复内置形象。来源按钮显示社区分享者，点击打开该形象的来源页；分享者未必是角色或作品的原作者。

启动优先使用显式 `--pet`，其次是上次有效选择，最后是内置小鸭。显式指定的无效本地目录会报错，不静默替换；历史选择损坏时则回退小鸭。切换形象不会改变人物设定、语音模型或任务执行能力。

## 文件边界

- `boxagent/pets/catalog.py`：公开目录、按需下载、校验、本地缓存、选择持久化。
- `boxagent/pets/network.py`：限定商店域名的 HTTPS 访问与 DNS 恢复。
- `boxagent/pets/window.py`：原生商店窗口和后台请求生命周期。
- `boxagent/pets/surface.py`：随系统外观变化的窗口背景。
- `boxagent/appearance/codex_pets.py`：后台图集准备、主线程视图装配、状态播放和透明行回退。
- `boxagent/desktop.py`：菜单入口与事务式视图更换。
- `boxagent/__main__.py`：启动形象恢复。

沿用 BoxAgent 的动画帧表、帧率与状态映射。V1 为 8 列 9 行，V2 为 8 列 11 行，每格 192×208。透明动画行回退待机，透明朝向格保留正常动画；待机行完全透明时拒绝使用。

下载缓存位于 `.runtime/pets/<id>/`，包含 `pet.json`、`spritesheet.webp`、`entry.json` 及可用的封面。`entry.json` 保存分享者、来源 URL、版本、站点许可字段和 SHA-256；未知许可保持空值。`selected.json` 保存当前选择。缓存与日志独立，并由 Git 忽略。

目录分页采用公开接口的 `page`、`pageSize`、`q`、`sort` 参数，完整资源在选择时通过 `/api/pets/<id>/share-data` 获取元数据。请求禁止重定向，资源路径限定为该形象的商店公开路径。图集限制为 12 MiB，必须通过 Pillow 的真实静态 WebP 解码与版本尺寸检查。缓存读写拒绝符号链接和路径越界，重新使用时验证哈希。

普通商店连接失败时，延用 AI-Companion 的网络恢复方式：经 Cloudflare 公共 DNS 查询商店 A 记录，仅连接公开地址，仍保留原域名的 SNI 与 TLS 证书校验。不修改系统代理、DNS 或证书设置。网络不可用时展示已下载形象；错误细节保留在终端诊断中，界面提供重试与离线入口。

切换先在后台下载、解码、切图，在主线程创建并试显示新视图，再提交选择；提交失败撤下新视图并保留原视图。成功后只替换形象视图与适配器引用，不重建 Runtime、语音会话或执行器。

## 验证

```sh
uv run --script scripts/pet.py --check
uv run --script scripts/pet.py --check-pets-ui
```

第二条会联网访问公开商店、下载真实 V1/V2 形象，并显示原生窗口。产物隔离在 `.runtime/pet-store-check/`；不更改产品当前选择，也不注册全局快捷键。

验收覆盖目录、搜索、分页、按钮切换、离线恢复、失败回滚、小鸭恢复、浅色／深色显示和首次未下载提示。并发验收使用真实 Runtime 配合等待中的执行器与语音替身，检查换装时任务与会话仍存在、输入草稿与位置不变；这不等同于实测云端语音或真实应用操作过程中换装。

2026-09-19 验证结果：39 项单元检查、21 项商店原生验收、26 项既有桌面 UI 回归检查通过。真实素材为 `guga`（V1）和 `gugahd`（V2）。独立 subagent 完成文案质检并复核浅色、深色与空状态截图，未发现阻塞性问题。报告与截图属于本机验收产物，不随源码提交。
