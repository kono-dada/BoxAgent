# 管理面板第一版视觉改造

2026-10-12，在 `codex/panel-visual` 实施。根据用户指定的本地 MiraJelly 参考，将管理页从通用文本卡片改为按内容组织的四种页面。视觉第一版已可运行，最终审美仍待用户体验反馈。桌宠和对话小窗属于 UI-P2，尚未改造。

## 本轮交付

- 共用浅色侧栏、页面标题、中文系统字体、控件、柔和选中态与细边框；自绘 SVG 图标，原生窗口按钮与可拖动标题区。
- 上下文顶部给出总量和分类构成；基础信息、正式历史、本轮参考、工具分别分组，保留完整条目和请求增删快照入口。Token 和缓存观测边界仍明确。
- 时间线按日期组织，区分正式产品消息和模型上下文条目，展示已有回合关联；兼容迁移前后的响应结构。
- 记忆以正文、类型、时间、来源展示；日志以时间、级别、摘要和模块展示，详情保留原始字段。
- 当前页搜索、加载/空态/断连恢复入口、窄窗口布局；详情 Escape 关闭、遮罩关闭与焦点恢复；页面切换保留搜索和滚动，旧异步响应不会覆盖新页面。

仍使用原有只读 IPC 白名单。未改变 Python Engine、会话/记忆存储或模型调用逻辑，未新增前端依赖。

- `pnpm --dir web/panel test`：5 项通过，覆盖 socket 分片与关联，以及统一事件流/旧产品消息/参考包/任务记录的不同响应结构。
- `pnpm --dir web/panel start -- --smoke`：19 项窗口检查通过，包含四页显示、搜索、完整内容读取、Escape 与焦点恢复、快速切换、空会话、滚动恢复及 760 px 窄窗口四页无横向溢出。
- 使用不存在的测试 socket 启动另一实例：断连恢复入口检查通过；未在真实 Engine 上人为断开连接验证重连周期。

- JavaScript 语法与 `git diff --check` 通过。没有修改 Python，因此本轮未重跑 Python 全量验证。

## 剩余边界

搜索只过滤已载入的数据；时间线限最近 150 条、记忆限 100 个节点、诊断限 100 条。当前时间线按日期排列并显示回合 ID，尚未提供按回合折叠与更早历史翻页。旧数据中的记忆内容质量由原记忆系统决定，这轮只改善展示。用户确认视觉方向后，继续调整密度和层次，并将同一套规范用到 UI-P2 小窗。
