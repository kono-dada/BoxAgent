## 运行默认值与升级

- 伙伴控制台：React 18 / TypeScript / Vite / Electron 38，renderer → preload IPC → Electron Main → `engine.sock` / `desktop.sock`。HTTP 只用于本机 3D 静态资源。原生桌宠和对话小窗仍为 AppKit。完整通道见 [架构](../BoxAgent-架构重构方案.md#44-伙伴控制台与前后端连接)。
- 决策模型默认 `auto`：有 DashScope Key / Workspace 时用阿里云 `decision-model-preview`，否则选 TypeSafe.ai。JEV 是历史称呼，不要求独立 TypeSafe Key。意图参考默认开启，`BOXAGENT_INTENT_REFERENCE=0` 可关闭，总准备预算 400 ms；不直接路由或启动任务。
- 当前 Query 参考包下一 Query 到期，正式消息与画像/Checkpoint 保留。删除会影响变化位置后的 KV 前缀，尚无可验证的计费缓存命中数据。Codex 移除临时任务轮后补回正式结果，不保留该轮原生工具细节，不撤销电脑动作。
- 新安装直接使用 `sessions/<id>/session.v1.jsonl` 与 `tasks/<task_id>/`；已有 `conversations/index.json` 时继续兼容布局，需先退出桌宠/Engine，再执行 `uv run --python 3.12 python scripts/migrate_sessions_v1.py --data-dir <数据目录>`。回滚追加 `--rollback`，导出最新正式历史到 `conversations-unified-rollback/`，保留源数据、任务与长期记忆。命令及锁规则见 [安装与升级](../setup.md#旧会话迁移与回滚)。
- `scripts/install.sh` 按锁安装和构建控制台；`--check` 检查控制台产物和 Electron 可执行文件，并检查所选决策模型凭据。已有本地环境覆盖继续有效。
