# 设置与主导航整理

2026-10-12，`codex/panel-visual`。参考本机 MiraJelly 的分类设置页，将日常使用、记录探索和低频配置按目的分开，保留原菜单的全部操作。

| 位置 | 内容 | 原因 |
|---|---|---|
| 主导航 | 对话与会话、长期记忆、Skill 管理、任务与运行记录 | 交流、探索伙伴的记忆、调整能力和跟进执行，都是产品的主要使用场景 |
| 主导航「观察」 | 有效上下文、事件时间线 | 用户明确需要上下文控制台与轨迹展示，直接进入便于观察每次 Query 与后续改动 |
| 左下角设置 → 3D 形象 | 实时 VRM 预览、选择并应用形象 | 配置伙伴外观；保留完整预览和应用行为 |
| 左下角设置 → 角色设定 | 名称、性格与互动方式（SOUL.md） | 配置伙伴的身份与表达 |
| 左下角设置 → 语音与桌面 | 麦克风、屏幕总结、桌面小窗、日志目录、退出伙伴 | 管理运行方式和桌面控制 |
| 左下角设置 → 诊断日志 | 日志列表、搜索、原始详情 | 低频排障 |
| 对话页快捷操作 | 麦克风、显示/收起小窗 | 高频开关保留一跳入口 |
| 任务页操作 | 允许/拒绝授权、停止后台任务、打开运行目录 | 与当前任务状态和产物放在一起 |

面板默认打开对话页。设置入口固定在会话列表下方，列表独立滚动；底部调整为设置与简短连接状态横排，完整 Engine 状态可悬停查看；设置概览提供四张分类卡片，分类页有标签与返回按钮。返回恢复之前主页面的搜索和滚动位置。760 × 680 窄窗口下分类卡片变为单列，设置入口持续可见。

MiraJelly 当前设置包含 general、floating-pet、voice、models、permissions、about；本轮依据 BoxAgent 已有真实能力做四类设置。模型/API、系统权限、主题/语言等尚无对应配置实现，未添加空页面或无效控件。参考文件：`/Users/bytedance/MiraJelly/app/src/design-system/AppSidebar.tsx` 与 `app/src/routes/settings/SettingsPage.tsx`。
