# Electron 统一桌面迁移验收

2026-10-12，`feat/electron-desktop`，接在控制台组件整理提交 `a1bb0ba` 之后。用户授权将桌宠、小窗、任务展示和控制台统一使用 Electron；Python Engine 与会话/模型能力继续复用。

## 当前交付

- 同一个 Electron Host 管理透明 VRM 桌宠、默认隐藏的 React 对话小窗和按需创建的 React 控制台。关闭控制台保留桌宠和 Engine；收起小窗保留 renderer、草稿和消息；按数据目录单实例运行。
- 小窗支持 Markdown / GFM、中文组合输入、Enter 发送 / Shift+Enter 换行、最近 30 次交互的正式历史与流式消息（读取最近 1000 条产品事件）、阅读历史时回到底部。会话切换保留各自草稿，迟到历史响应不能串入新会话。
- 小窗和控制台共用 TaskStatus，显示进度、耗时、长时间未更新、授权 / 拒绝 / 停止与错误。继续使用原 Engine API，任务执行期间仍可聊天。
- 小窗恢复随内容变化的高度：空闲约 270px、最大 480px、宽 392px；历史和任务内部滚动。半透明蓝紫/薄荷渐变光场缓慢流动，语音状态调整强度，隐藏或系统减少动态效果时暂停。背景为 CSS 程序化视效，未复制 MiraJelly 视频。
- 深色小窗使用稳定的消息/输入底色与高对比度正文、辅助文字和占位提示；流光主要保留在边缘。新会话入口改为带加号、底色与边框的按钮，展开状态可感知，中英文底部操作均保持可见。
- 共用中英文、浅色 / 深色 / 跟随系统；跨窗口同步偏好。桌宠保持透明，普通展示不抢焦点，小窗输入可聚焦。菜单保留控制台、新会话和退出，快捷键切换语音。
- 复用 Three.js / three-vrm 播放器、动作与物理；Electron 负责鼠标跟随、拖动、边界裁剪、屏幕内布局、大小和位置。旧位置坐标首次读取转换，新位置保存为 v2。
- 换装先加载候选窗口，收到真实 VRM ready 后提交选择并替换；资源/渲染失败保留旧窗口和选择。大小偏好恢复，屏幕尺寸限制实际渲染尺寸。
- 形象加载失败显示中英文可读提示，损坏模型的原始解析错误写入 `logs/desktop-service.log`；小窗支持关闭提示，控制台避免重复显示相同错误。
- Python DesktopService 提供资源 HTTP、角色文件、运行归属验证与 Engine 监督，由 Electron 通过 stdio JSONL 管理。关闭 stdin 清理 Engine 和 HTTP，再刷新日志；超时强制退出。
- 删除旧 AppKit 窗口、WebKit wrapper、主线程桌面控制队列、desktop.sock 和过时 UI 检查脚本。资源目录移动到 `interfaces/desktop/`；WebKit 从宿主锁文件移除。Cocoa/Quartz 保留供本地截屏等后端能力使用。

## 使用

先退出旧版本，再构建并启动：

```bash
pnpm --dir web/vrm build
pnpm --dir web/panel install --frozen-lockfile
pnpm --dir web/panel build
./scripts/run-pet.sh
```

新安装可直接运行 `./scripts/install.sh`。现有 Session、记忆、角色文件与形象选择继续使用原运行目录，不要求迁移会话。独立 `pnpm --dir web/panel start` 只连接 Engine；日常通过完整桌宠的菜单打开控制台。

旧 `pet.py --check-ui`、`--check-vrm-ui`、`--check-pet-size-ui` 和 `--smoke-desktop` 统一映射到隔离 Electron 桌面检查；真实音频/任务验收使用脚本文档里的专门 E2E 入口。
