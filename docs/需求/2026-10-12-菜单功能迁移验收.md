# 原菜单功能迁入伙伴控制台

2026-10-12，`codex/panel-visual`。此前四个管理页不足以覆盖产品入口。本轮按 `interfaces/macos/menu.py` 的全部原入口逐项补齐，不要求用户为了设置形象或角色回到原始 AppKit 管理窗口。

| 原入口 | 面板位置与行为 |
|---|---|
| 显示/收起对话 | 对话与会话、设置 → 语音与桌面；操作原生小窗 |
| 新建会话 | 对话与会话；另支持查看、激活、归档、发消息 |
| 开启/关闭麦克风 | 对话与会话、设置 → 语音与桌面；保留原快捷键 |
| 编辑角色设定 | 设置 → 角色设定；名称和 SOUL.md 保存并应用 |
| 3D 形象子菜单 | 设置 → 3D 形象；真实 VRM 预览与应用；原宿主首帧就绪后替换，失败保留原形象 |
| 记忆看板 | 长期记忆；图与列表、节点字段、关系探索、删除 |
| Skill 管理 | Skill 管理；内置可启停，用户可新建/编辑/删除 |
| 当前会话最近运行 | 任务与运行记录；打开最近运行 |
| 当前会话运行记录 | 任务与运行记录；按会话列出目录与 manifest，打开产物/会话目录 |
| 诊断日志 | 设置 → 诊断日志，以及语音与桌面中的原生目录入口 |
| 开启/关闭屏幕总结 | 设置 → 语音与桌面；显示摘要与已有状态 |
| 停止后台任务 | 任务与运行记录；另支持允许/拒绝待办授权 |
| 退出 BoxAgent | 设置 → 语音与桌面；确认后退出原宿主，关闭 Engine；单独关闭面板保留桌宠 |

导航位置按 [设置与主导航整理](<2026-10-12-设置与主导航整理.md>) 更新；原菜单入口不删减。

原菜单新增「伙伴控制台…」。所有原入口继续保留；面板已成为完整入口。日常桌宠小窗外观仍属于 UI-P2，本轮不宣称完成小窗视觉替换。

## 实现边界

复用原 Engine 命令处理会话、文字/语音、屏幕总结、任务、Skill 和记忆。新增 `desktop.sock` 连接桌面宿主；socket 线程只收发，AppKit 主线程处理形象/小窗/角色/目录动作。只允许目录清单中的有效形象；打开运行必须匹配会话 manifest；未知命令拒绝；排队请求超时取消后不再执行。

角色保存使用临时文件替换，名称无效保留原文件。原 Engine 文件监听在安全时机同步 SOUL.md。形象预览采用原 AssetServer/Three.js 渲染，随机 URL 只在本机使用，资源继续走精确文件白名单。面板进程禁用 Node integration，保留 context isolation/sandbox，IPC 扩展为列明的功能白名单。
