# BoxAgent 真人录屏脚本

目标时长：4～6 分钟。不要追求模型逐字复现；只要能力和事件顺序真实即可。

## 录制画面

1. 新建一个专用 macOS 桌面空间，关闭微信、飞书、Codex、终端和文件列表。
2. 用一张纯色或渐变图片全屏铺底；不要直接露出真实桌面、菜单栏通知和桌面文件。
3. 只在录制区内保留：BoxAgent 对话面板、桌宠、音乐 App、Safari，以及随后打开的管理窗口。
4. 使用 `Command + Shift + 5`，选择“录制所选部分”，框住约 16:9 的演示区域，不录整块屏幕。
5. “选项 → 麦克风”选择实际说话的麦克风。若使用系统录屏，伙伴的声音需要从扬声器播放，才能一并被麦克风录入；戴耳机时系统录屏通常录不到伙伴的声音。
6. 开启勿扰模式；把音乐音量调低到 15%～25%，伙伴语音调到清晰可闻。

## 开场准备

- 点击菜单栏的 BoxAgent 图标，选择“新建会话…”，输入“产品演示”。
- 确认角色名随当前形象显示，不出现 `BoxAgent` 或旧角色名。
- 打开语音，等状态变为“正在聆听”后再开始。
- Safari 保持一个空白窗口；音乐 App 可关闭或最小化。

## 一镜到底对话

### 1. 角色与全双工

你说：

> 你好，你是谁？简单介绍一下自己。

伙伴开始回答后，在它说完前自然打断：

> 等等，短一点说。

验收点：伙伴停止上一段播报，转为聆听，并用更短的回答继续；画面同时显示语音转写。

### 2. 自动长期记忆

你说：

> 我喜欢桂花乌龙，回答时希望你先说结论，而且尽量简洁。

等伙伴正常回应。无需说“请记住”；这句话落盘后，记忆系统应在后台异步判断和存储。

### 3. 音乐任务与并行聊天

你说：

> 打开音乐 App 播放一首歌，确认真的开始播放。

看到任务卡显示“执行中”后，不等任务结束，继续说：

> 你忙的时候我们继续聊。今天星期几？再简短夸我一句。

验收点：

- 前台伙伴立即继续聊天；
- 后台任务卡仍在执行；
- 音乐真正开始播放；
- 任务结束后伙伴主动语音提醒，任务结果排在并行聊天之后。

### 4. 知乎只读任务

你说：

> 用 Safari 去知乎找一篇最近关于 AI Agent 记忆的文章，打开让我看看；不要点赞、关注或评论。

验收点：使用知乎只读 Skill；只搜索、浏览和打开文章，不产生社交副作用。

### 5. 从真实轨迹创建并安装 Skill

知乎任务成功后说：

> 把刚才这段知乎找文章的成功轨迹沉淀成一个 Skill，并安装。

如果伙伴先展示草稿并等待确认，再说：

> 确认安装。

验收点：

- 先读取刚完成任务的真实轨迹；
- 检查现有 Skill，避免重复；
- 生成可查看的草稿；
- 只有明确确认后才安装；
- Skill 管理页能看到新 Skill 已启用。

### 6. 管理能力

依次从菜单打开：

1. 记忆看板：展示刚才的饮品与回答偏好，以及图谱关系；
2. Skill 管理：展示内置音乐 Skill、知乎 Skill 和刚创建的 Skill；
3. 形象商店：默认进入“已下载”，立即显示当前形象，不等待远端商店。

每个窗口停留 3～5 秒即可，不展示本地路径、Key、日志原文或私人历史。

### 7. 跨 Session 召回收尾

新建另一个 Session，然后说：

> 我们换了一个新会话。你还记得我喜欢喝什么，以及我希望你怎么回答吗？

验收点：回答包含“桂花乌龙”“先说结论”“简洁”，证明不是当前短期历史，而是跨 Session 记忆召回。

结尾画面：桌宠、简短记忆回答、音乐播放状态和已完成任务卡同时可见。

## 录制失败时不要硬撑

- 语音未转写：停止录制，重开语音后重录，不改用文本冒充语音。
- 后台任务超过合理时间：保留失败证据，修复后再录，不剪辑成成功。
- Skill 草稿无效或安装失败：先检查草稿 ID 与真实任务轨迹，再重录该段。
- 在线知乎不可达：明确展示网络受阻，不要预先打开页面冒充 Agent 完成。
- 形象商店在线目录不可达：只展示“已下载”；不要把网络问题说成商店加载成功。
